# Context

mcupdater updates a stopped Minecraft server: the game, its mod loader, and its
configured mods. It shows a plan first, and only replaces files it can account
for.

## Glossary

- **Server directory**: The directory the server runs from (`server_dir`).
- **Managed file**: A file recorded in `.mcupdater/state.json`, because
  mcupdater installed it. Managed files may be replaced or removed by an
  update and are moved to the backup.
- **Unmanaged file**: Any file in the server directory not recorded in state.
  mcupdater never replaces one unless it is adopted or acknowledged.
- **Collision**: An unmanaged file at a path an update would write. It blocks
  the plan with an error naming the path.
- **Acknowledged file**: An unmanaged file listed in `replace_unmanaged`, which
  the administrator allows mcupdater to replace.
- **Layout**: How a Fabric server's files are arranged.
  - **Installer layout**: Vanilla `server.jar`, `fabric-server-launch.jar`, and
    `libraries/`, produced by running the Fabric installer.
  - **Launcher layout**: One executable Fabric launcher (`launcher_file`) that
    downloads vanilla and libraries into `.fabric/` when the server starts.
- **Launcher**: The jar generated by Fabric meta. It is the Maven
  `fabric-installer-<v>-server.jar` plus `install.properties` naming a loader
  and Minecraft version.
- **Verified launcher**: A launcher shown to match the checksummed Maven
  installer for the version it declares, entry for entry, with nothing added
  except `install.properties`.
- **Adopt**: Take over a verified launcher that mcupdater did not install, as if
  it were managed.
- **Conversion**: An update that changes the Fabric layout or launcher file.
  Managed files that the new layout no longer produces are removed (moved to
  the backup).
- **Plan**: The output of `check` (and the first part of `update`): target
  versions, adoptions, conversions, and per-mod changes.
- **Downgrade**: A planned mod version published before the installed one,
  usually because an installed prerelease is excluded by
  `allow_prerelease: false`.
